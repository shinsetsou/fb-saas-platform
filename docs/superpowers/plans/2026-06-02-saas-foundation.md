# SaaS Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the first runnable Laravel SaaS foundation for the Facebook Page calendar assistant: auth, workspace creation, trial state, bot settings, and a dashboard shell.

**Architecture:** Scaffold a Laravel app with Breeze authentication and Blade views. Model each customer business as a `Workspace` owned by the signed-in user, with related trial state and bot settings created automatically during registration.

**Tech Stack:** Laravel 11 or current Composer-resolved Laravel version, Laravel Breeze Blade stack, MySQL or SQLite for local development, PHPUnit/Pest feature tests, Vite/Tailwind from Breeze.

---

## Scope

This plan implements the first foundation slice from `docs/superpowers/specs/2026-06-02-facebook-page-calendar-saas-design.md`.

- [ ] **Step 4: Create workspace creation action**

Create `app/Actions/Workspaces/CreateWorkspaceForUser.php`:

```php
<?php

namespace App\Actions\Workspaces;

use App\Models\User;
use App\Models\Workspace;
use Illuminate\Support\Str;

class CreateWorkspaceForUser
{
    public function handle(User $user): Workspace
    {
        $baseName = "{$user->name} Workspace";

        $workspace = Workspace::create([
            'name' => $baseName,
            'slug' => $this->uniqueSlug($baseName),
            'timezone' => config('app.timezone', 'UTC'),
        ]);

        $workspace->users()->attach($user->id, ['role' => 'owner']);

        $workspace->trial()->create([
            'starts_at' => now(),
            'ends_at' => now()->addDays(14),
            'status' => 'trialing',
        ]);

        $workspace->botSetting()->create([
            'is_enabled' => false,
            'business_name' => $baseName,
            'booking_timezone' => $workspace->timezone,
            'default_appointment_duration_minutes' => 30,
            'buffer_minutes' => 0,
        ]);

        return $workspace;
    }

    private function uniqueSlug(string $name): string
    {
        $slug = Str::slug($name);
        $candidate = $slug;
        $counter = 2;

        while (Workspace::where('slug', $candidate)->exists()) {
            $candidate = "{$slug}-{$counter}";
            $counter++;
        }

        return $candidate;
    }
}
```

```php
<?php

namespace App\Http\Controllers;

use Illuminate\Http\Request;

class BotSettingsController extends Controller
{
    public function edit(Request $request)
    {
        $workspace = $request->user()->workspaces()->with('botSetting')->firstOrFail();

        return view('bot-settings.edit', [
            'workspace' => $workspace,
            'settings' => $workspace->botSetting,
        ]);
    }

    public function update(Request $request)
    {
        $workspace = $request->user()->workspaces()->with('botSetting')->firstOrFail();

        $validated = $request->validate([
            'is_enabled' => ['nullable', 'boolean'],
            'business_name' => ['required', 'string', 'max:255'],
            'business_description' => ['nullable', 'string', 'max:5000'],
            'default_appointment_duration_minutes' => ['required', 'integer', 'min:15', 'max:480'],
            'booking_timezone' => ['required', 'timezone'],
            'buffer_minutes' => ['required', 'integer', 'min:0', 'max:240'],
            'cancellation_instructions' => ['nullable', 'string', 'max:2000'],
            'bot_tone' => ['nullable', 'string', 'max:1000'],
        ]);

        $validated['is_enabled'] = $request->boolean('is_enabled');

        $workspace->botSetting->update($validated);

        return redirect()
            ->route('bot-settings.edit')
            ->with('status', 'bot-settings-updated');
    }
}
```
